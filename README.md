# Bitu Kumar Portfolio

A premium, responsive developer portfolio built with React 19, Vite, Framer Motion, and CSS Modules-inspired custom styling.

## Features
- Premium dark UI with glassmorphism and animated sections
- Smooth motion transitions and hover interactions
- Responsive layout for mobile, tablet, laptop, and desktop
- About, skills, experience, projects, education, GitHub, and contact sections
- Contact form integration ready for EmailJS

## Development
```bash
npm install
npm run dev
```

## Build
```bash
npm run build
```

## Deployment on Vercel
1. Push the project to GitHub.
2. Import the repository in Vercel.
3. Set the build command to `npm run build`.
4. Set the output directory to `dist`.
5. Deploy.
